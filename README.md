# Cartographie Google Ozans — Châteauroux

Dépôt statique prêt pour GitHub Pages. Importer son contenu à la racine et activer Pages sur `main / root`.

- `apps/cards/` : cartes, synthèse, vigilances et sources
- `apps/network/` : nuage relationnel
- `data/` : référentiel structuré évolutif

## Architecture des assets
- `assets/css/common.css` : règles partagées
- `assets/css/landing.css` : page d’accueil
- `assets/css/cards.css` : cartographie en cartes
- `assets/css/network.css` : réseau relationnel
- `assets/js/data-loader.js` : utilitaires partagés
- `assets/js/cards.js` : interactions de la vue cartes
- `assets/js/network.js` : interactions du réseau

- `data/content.json` : synthèse des oppositions et points de vigilance
